Pictures of the desktops Armbian publishes, for Simple mode's Armbian choice.
Scaled down to 640x360 WebP. A desktop without a picture here gets a plain
card with its name.

- `gnome.webp`: "Debian 13.0.0 GNOME Files 48.3 default - English.png",
  https://commons.wikimedia.org/wiki/File:Debian_13.0.0_GNOME_Files_48.3_default_-_English.png
  Author: The Debian Project. Licence: GPL-2.0-or-later (free software
  screenshot). Cropped to 16:9 from the top.
- `kde-plasma.webp`: "KDE Plasma 6 screenshot.png",
  https://commons.wikimedia.org/wiki/File:KDE_Plasma_6_screenshot.png
  Author: KDE (from https://kde.org/announcements/megarelease/6/). Licence:
  GPL (free software screenshot).

Xfce, Cinnamon and the others have no picture yet: Armbian does not publish
them for the TaishanPi 3M or the CM5-IO.
